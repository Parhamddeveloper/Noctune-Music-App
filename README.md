# Noctune

Noctune is a responsive music player built with React, TypeScript, Redux Toolkit, React Router, and Tailwind CSS.

## Features

- Play and pause songs
- Next and previous track controls
- Volume and mute controls
- Seek through the current song
- Shuffle and repeat modes
- Favorite songs
- Create playlists
- Add songs to playlists
- LocalStorage persistence
- Responsive mobile-first design

## Tech Stack

- React
- TypeScript
- Redux Toolkit
- React Router
- Tailwind CSS
- Lucide React
